### 2. 注册时手机号唯一性防并发

**问题：** `IsPhoneAlreadyTaken` + `user.Insert` 之间非原子操作，并发注册时可能产生同一手机号多个账号。

**方案：** 给 `model/user.go` 中 `Phone` 字段增加 `uniqueIndex`：
```go
Phone string `json:"phone" gorm:"uniqueIndex" validate:"max=20"`
```
注册时直接 `Insert`，捕获 GORM 唯一性冲突错误。

**涉及文件：**
- `model/user.go` — 修改 User 结构体字段标签
- `sidecar/controller/phone_auth.go` — 注册逻辑改用唯一性冲突捕获

### 4. 验证码存储迁移到 Redis

**问题：** 当前验证码存储在内存 `verificationMap` 中，服务重启丢失，分布式部署不共享限流状态。

**方案：** 将 `common/verification.go` 中的内存 map 替换为 Redis：
```go
redisKey := fmt.Sprintf("verify:%s:%s", purpose, key)
common.RedisSet(redisKey, code, time.Duration(common.VerificationValidMinutes)*time.Minute)
```

同步改造 `sidecar/service/sms.go` 中的发送限流 `sync.Map` 也改为 Redis。

**涉及文件：**
- `common/verification.go`
- `sidecar/service/sms.go`
